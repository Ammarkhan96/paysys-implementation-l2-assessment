# Paysys Labs - L2 Assessment Submission

This repository contains the complete solution for the Implementation & L2 Support Engineer Technical Assessment.

## Repository Layout
* `database/` & `sql/`: Schema, analytics queries, and performance optimization report.
* `kubernetes/`: Corrected deployment and service manifests.
* `python/`: L2 Support diagnostic CLI tool.
* `tests/`: Automated API (Pytest) and UI (Playwright) test suites.
* `investigation/`: Root Cause Analysis reports for all production incidents.
* `evidence/`: System health outputs and diagnostic scripts.
